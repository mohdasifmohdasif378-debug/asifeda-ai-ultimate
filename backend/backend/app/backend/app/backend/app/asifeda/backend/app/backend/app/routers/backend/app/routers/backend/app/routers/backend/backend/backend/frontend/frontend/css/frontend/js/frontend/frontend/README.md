# AsifEdA AI — Smart Exam Preparation Platform

An AI-powered educational platform for competitive exam preparation (UPSC, SSC, NDA, NEET, JEE, JKSSB).

## Features

- 🔐 **Secure Authentication** — JWT-based login/register with bcrypt password hashing
- 🤖 **AI Chat** — Powered by Anthropic Claude for exam-focused Q&A
- 📱 **Responsive Design** — Glassmorphism UI, mobile-friendly
- 🐳 **Docker Ready** — One-command deployment
